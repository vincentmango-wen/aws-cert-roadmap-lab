## Scope and decision

The preceding article and question work (#363 / #367 and #364 / #370) is complete on the verified master snapshot. Correct only the localized IAM and CloudWatch basics articles. - **IAM:** Keep IAM user, group, role and policy as study concepts, but distinguish them from the recommended access model. Prefer identity federation (for example, IAM Identity Center) and temporary credentials for human access, and IAM roles with temporary credentials for workloads. Avoid routine root use; reserve long-lived credentials for exceptions that require them. Use the Japanese version as the baseline for the English and Traditional Chinese correction, with only a small Japanese clarification of the long-lived credential exception. [IAM security best practices](https://docs.aws.amazon.com/IAM/latest/UserGuide/best-practices.html).

Distinguish free basic monitoring (status checks one minute, other default metrics five minutes), paid detailed monitoring (default instance metrics one minute), and the opt-in metric category adding a 10-second CPU utilization metric. Distinguish that metric from the separate no-additional-charge performance status checks on supported accelerated instances. Do not claim default behavior changed. Keep the Japanese recap consistent. [EC2 monitoring guide](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/manage-detailed-monitoring.html) · [AWS announcement](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-performance-status-checks/).
