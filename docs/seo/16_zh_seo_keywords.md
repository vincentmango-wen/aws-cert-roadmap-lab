## 2. Basic Policy

For this site's Chinese SEO, target the following combinations rather than broad keywords alone (Traditional Chinese keyword specimens are retained in their original language throughout this document).

```text
AWS 認證
× 初學者
× Cloud Practitioner
× SAA-C03
× 服務比較
× 架構圖
× Serverless
× 作品集
```

Avoid terms such as "practice exam" and "題庫" that compete directly with major English- and Chinese-language learning sites.

This site primarily targets the following.

- Understanding terminology for AWS beginners
- Cloud Practitioner / SAA learning roadmaps
- AWS service comparisons
- AWS architecture diagrams
- AWS serverless architectures
- Building portfolios with AWS

## 10. Keywords Not to Target

Do not target the following, even if they generate search traffic.

| Keyword | Reason not to target |
|---|---|
| AWS 題庫 | Easily mistaken for exam dump content |
| AWS CCP 題庫 | Search intent includes seeking copies of actual exam questions |
| AWS SAA 題庫 | Search intent includes seeking copies of actual exam questions |
| AWS 考古題 | Easily mistaken for exam dumps |
| AWS 真題 | Strong search intent for leaked actual exam questions |
| AWS 考試答案 | Strong search intent for cheating on exams |
| AWS dumps | Prohibited expression |
| AWS exam dump | Prohibited expression |
| AWS 保證通過 | Passing cannot be guaranteed |
| AWS 快速通過 | Leans toward low-quality exam hacks |

Use the following Traditional Chinese expressions on this site.

- 練習題
- 模擬試題
- 例題
- 解說
- 學習重點
- 考試準備

## 12. Meta Title / Description Rules

### Title Rules

Original localized template; `{主キーワード}` denotes the primary keyword.

```text
{主キーワード}｜AWS資格ロードマップラボ
```

Examples (original localized title specimens):

```text

```

### Description Rules

Original mixed-language description specimen; `{主題}` denotes the topic.

```text
AWS初學者向けに、{主題}を用語、比較表、架構圖、練習題で整理します。Cloud Practitioner / SAA-C03 の學習に役立つ非官方學習內容です。
```

### Notes

- Do not use "官方".
- Do not use "保證通過".
- Do not use "真題" or "題庫".
- Retain official AWS names in English.
- Prefer official service names such as Amazon S3 / AWS Lambda.
