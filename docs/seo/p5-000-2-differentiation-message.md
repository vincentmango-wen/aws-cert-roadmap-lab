## 2. 差別化方針

## 2.1 中心メッセージ

AWS Cert Roadmap Lab は、AWS資格学習を「暗記」ではなく、用語・比較・問題演習・構成図・サーバーレス実装で理解する学習サイトである。

## 2.2 競合との差別化軸

| 軸 | 差別化内容 |
|---|---|
| 図解 | AWSサービスを単体暗記ではなく、構成図で理解する |
| 比較 | S3 / EBS / EFS、RDS / DynamoDB など、試験で混同しやすいサービスを比較する |
| 実装 | S3、CloudFront、Lambda、API Gateway、DynamoDB などを実際のポートフォリオ構成に接続する |
| 初学者向け | Cloud Practitioner から SAA へ進む学習者を対象にする |
| 多言語 | 日本語・英語・繁体字中国語で同じ学習導線を提供する |
| 非ダンプ | 本番試験問題のコピーではなく、独自作成の学習コンテンツとして提供する |

## 2.3 狙う印象

| 対象ユーザー | 持ってほしい印象 |
|---|---|
| AWS初学者 | サービスの違いを図と比較で理解できる |
| CLF受験者 | 基礎用語と試験ポイントを整理できる |
| SAA学習者 | 構成図を通じて設計パターンを理解できる |
| 海外ユーザー | 日本発だが英語・繁体字中国語でも読めるAWS学習サイト |
| 採用担当者 | AWS資格学習を実装・設計・公開まで落とし込んだポートフォリオ |

## 7.3 AWSサービス名の扱い

AWSサービス名は、英語・中国語ページでも原則として正式名称または一般的な略称を維持する。

例：

- Amazon S3
- Amazon CloudFront
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon CloudWatch
- AWS Identity and Access Management
- IAM
