## 2. Differentiation Policy

## 2.1 Core Message

AWS Cert Roadmap Lab is a learning site for understanding AWS certification topics through terminology, comparisons, practice questions, architecture diagrams, and serverless implementation rather than memorization.

## 2.2 Differentiation from Competitors

| Dimension | Differentiation |
|---|---|
| Visual explanation | Understand AWS services through architecture diagrams rather than memorizing them individually |
| Comparison | Compare services commonly confused in exams, such as S3 / EBS / EFS and RDS / DynamoDB |
| Implementation | Connect S3, CloudFront, Lambda, API Gateway, DynamoDB, and other services to a real portfolio architecture |
| Beginner focus | Target learners progressing from Cloud Practitioner to SAA |
| Multilingual | Provide the same learning journey in Japanese, English, and Traditional Chinese |
| Not exam dumps | Provide independently created learning content rather than copies of actual exam questions |

## 2.3 Intended Impressions

| Target user | Intended impression |
|---|---|
| AWS beginners | Understand differences between services through diagrams and comparisons |
| CLF candidates | Organize basic terminology and exam points |
| SAA learners | Understand design patterns through architecture diagrams |
| International users | An AWS learning site originating in Japan that is also readable in English and Traditional Chinese |
| Recruiters | A portfolio carrying AWS certification study through implementation, design, and publication |

## 7.3 Handling AWS Service Names

As a rule, retain official AWS service names or common abbreviations on English and Chinese pages as well.

Examples:

- Amazon S3
- Amazon CloudFront
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon CloudWatch
- AWS Identity and Access Management
- IAM

## 7.4 Expressions to Avoid

Do not use the following expressions (original localized specimens).

- real exam questions
- actual exam dumps
- guaranteed pass
- pass AWS exam in X days
- leaked questions
- 本番試験問題
- 試験ダンプ
- 合格保証
- 外流考題
- 真實考題
- 保證通過
