If executed via the Workflow tool, Track 1 / Track 2 / Track 3 run as parallel branches of a `parallel()` call, with Track 3's two tasks run as a `pipeline()` internally (sequential, same worktree).

**Goal:** Close 4 open GitHub issues (#314 ACR-005, #315 ACR-006, #316 ACR-007, #319 ACR-009) with 4 merged PRs, each passing its own acceptance criteria, with zero file-level conflicts between the 3 parallel tracks.

**Architecture:** 3 isolated git worktrees on local disk (NOT the SMB-mounted primary working directory), each on its own branch off `origin/master`. **Tech Stack:** Next.js 16 (App Router, `output: "export"`), React 19, TypeScript, Tailwind, Vitest (no jsdom/testing-library — this repo deliberately avoids that dependency, see `frontend/src/components/questions/__tests__/question-player-ssr-content.test.tsx` header comment).

## Global Constraints

- Never run `npm ci` / `npm run build` / `npm test` / `npm run lint` / `npm run typecheck` inside `/Volumes/DevShare/...` (SMB mount) — `node_modules` there has a known EACCES bug (memory: `smb-build-workaround`). All builds/tests happen inside the local-disk worktrees created in Task 1.
- Package manager is npm (`frontend/package-lock.json`); ignore `pnpm-lock.yaml`, CI does not use it.
- Every branch is created from `origin/master` (not `dev` — `dev` is fully absorbed into `master`, confirmed 2026-08-06).
- Do not add `@testing-library/react` or `jsdom` — this codebase's established convention is pure-function tests or `react-dom/server`'s `renderToStaticMarkup` for anything that needs rendering.
- 1 GitHub Issue = 1 PR. Push → PR → squash merge → delete remote branch, with no additional confirmation checkpoint per ticket (per user approval in `docs/superpowers/specs/2026-08-06-acr005-006-007-009-orchestration-design.md`).
- If two tracks' PRs would both touch the same dictionary file (`frontend/src/i18n/dictionaries/{ja,en,zh}.ts`) — Track 2 (ACR-009, no dictionary edits) and Track 3/ACR-007 (adds pagination keys) — whichever merges second must `git fetch && git rebase origin/master` before its final push.

- No other files change (dictionary already has full `footer` translations for ja/en/zh, confirmed 2026-08-06)

**Interfaces:**

- Produces: nothing consumed by other tasks (Track 2 is a leaf).

**Design decisions locked in during planning (record these in the PR body):**
1. **Locale detection**: self-detect via `usePathname()` + `getLocaleFromPathname()`, exactly like `Header.tsx` — no `locale` prop, no change to `SiteLayout.tsx` or any page file (`SiteLayout.tsx` currently passes no locale to `Header` either, confirming this is the established pattern here).
2. **Brand name/copyright**: use `getDictionary(locale).site.name` for the brand link text. This is internally consistent with `getDictionary(locale).footer.copyright`, which already embeds the same site name per locale (verified: ja/en identical either way; zh: dictionary's `site.name` and `footer.copyright` already agree on "AWS 認證學習路線圖實驗室"). Note in the PR: `Header.tsx` has its own separate local zh string ("AWS證照路線圖實驗室") that differs from the dictionary's zh site name — this is a pre-existing inconsistency between Header's local literal data and the shared dictionary, not something this ticket fixes (Header.tsx is untouched; flagging as a follow-up, not fixing unilaterally per the issue's own "独断で変えない" caution).
3. **"利用規約" (Terms of Service) link**: this page exists only at `/terms-of-service` (ja-only, confirmed — no `/en/terms-of-service` or `/zh/terms-of-service` route exists, and it is not part of `NavigationKey`/the dictionary's `footer.sections`). Render it only when `currentLocale === "ja"`, with its href left unlocalized (`/terms-of-service`, never passed through `createLocalizedPath`). This satisfies the acceptance criterion "フッター内リンクが locale 対応（/en からのリンクが ja ページへ流出しない）" by omission rather than linking to a Japanese-only document from an English footer.
4. **Section order**: `learning`, `siteInfo`, `portfolio` — matches `FooterSectionKey` and the current hardcoded order.

- [ ] **Step 1: Rewrite Footer.tsx**

Replace the full contents of `$SB/wt-acr009/frontend/src/components/layout/Footer.tsx`:

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";
import type { ReactElement } from "react";
import { getDictionary } from "@/i18n/dictionaries";
import {
  createLocalizedPath,
  getLocaleFromPathname,
} from "@/i18n/locales";
import type { FooterSectionKey, NavigationKey } from "@/i18n/dictionaries";

type ExternalFooterLink = {
  labelKey: NavigationKey;
  href: string;
};

const PORTFOLIO_EXTERNAL_LINKS: ExternalFooterLink[] = [
  {
    labelKey: "github",
    href: "https://github.com/vincentmango-wen/aws-cert-roadmap-lab",
  },
  { labelKey: "note", href: "https://note.com/fumi_ai_202507" },
  { labelKey: "x", href: "https://x.com/fumikun_gengen" },
];

const INTERNAL_SECTION_ORDER: FooterSectionKey[] = [
  "learning",
  "siteInfo",
  "portfolio",
];

function isExternalPortfolioKey(key: NavigationKey): boolean {
  return PORTFOLIO_EXTERNAL_LINKS.some((link) => link.labelKey === key);
}

export function Footer(): ReactElement {
  const pathname = usePathname();
  const currentLocale = getLocaleFromPathname(pathname ?? "/");
  const dictionary = getDictionary(currentLocale);
  const labels = dictionary.footer;

  return (
    <footer className="border-t border-slate-200 bg-white">
      <div className="mx-auto w-full max-w-7xl px-4 py-8 sm:px-6 lg:px-8">
        <div className="grid gap-8 sm:grid-cols-2 lg:grid-cols-4">
          <div className="sm:col-span-2 lg:col-span-1">
            <Link
              href={createLocalizedPath(currentLocale, "/")}
              className="inline-flex text-base font-bold !text-slate-950 underline-offset-4 hover:underline"
            >
              {dictionary.site.name}
            </Link>
            <p className="mt-3 max-w-sm text-sm leading-6 text-slate-600">
              {labels.description}
            </p>
          </div>

          {INTERNAL_SECTION_ORDER.map((sectionKey) => {
            const section = labels.sections[sectionKey];

            return (
              <section
                key={sectionKey}
                aria-labelledby={`footer-${sectionKey}`}
              >
                <h2
                  id={`footer-${sectionKey}`}
                  className="text-sm font-semibold text-slate-950"
                >
                  {section.title}
                </h2>
                <ul className="mt-3 space-y-2">
                  {section.linkKeys.map((linkKey) => {
                    const label = dictionary.navigation[linkKey];

                    if (isExternalPortfolioKey(linkKey)) {
                      const external = PORTFOLIO_EXTERNAL_LINKS.find(
                        (link) => link.labelKey === linkKey,
                      );

                      if (!external) {
                        return null;
                      }

                      return (
                        <li key={linkKey}>
                          <a
                            href={external.href}
                            target="_blank"
                            rel="noopener noreferrer"
                            className="text-sm text-slate-600 underline-offset-4 transition hover:text-slate-950 hover:underline"
                          >
                            {label}
                          </a>
                        </li>
                      );
                    }

                    return (
                      <li key={linkKey}>
                        <Link
                          href={createLocalizedPath(currentLocale, `/${linkKey}`)}
                          className="text-sm text-slate-600 underline-offset-4 transition hover:text-slate-950 hover:underline"
                        >
                          {label}
                        </Link>
                      </li>
                    );
                  })}
                  {sectionKey === "siteInfo" && currentLocale === "ja" ? (
                    <li>
                      <Link
                        href="/terms-of-service"
                        className="text-sm text-slate-600 underline-offset-4 transition hover:text-slate-950 hover:underline"
                      >
                        利用規約
                      </Link>
                    </li>
                  ) : null}
                </ul>
              </section>
            );
          })}
        </div>

        <div className="mt-8 border-t border-slate-200 pt-6">
          <p className="text-xs leading-6 text-slate-500">
            {labels.copyright}
          </p>
        </div>
      </div>
    </footer>
  );
}
```

Note on the `href` computation: `NavigationKey` values for the `learning` section (`terms`, `comparisons`, `questions`, `architectures`, `blog`, `roadmap`) and `siteInfo` section (`about`, `contact`, `privacy`, `disclaimer`) already match their route paths 1:1 — verified against `Header.tsx`'s `navItems` hrefs and the original hardcoded `Footer.tsx` hrefs during planning (both use plain `/about`, `/contact`, `/privacy`, `/disclaimer`, `/terms`, etc.), so `` `/${linkKey}` `` is safe as-is with no further lookup needed.

```ts
export const QUESTIONS_PER_PAGE = 10;

export function getTotalPages(itemCount: number, pageSize: number): number {
  if (itemCount <= 0) {
    return 1;
  }

  return Math.ceil(itemCount / pageSize);
}

export function clampPage(page: number, totalPages: number): number {
  if (page < 1) {
    return 1;
  }

  if (page > totalPages) {
    return totalPages;
  }

  return page;
}

export function paginate<T>(items: T[], page: number, pageSize: number): T[] {
  const totalPages = getTotalPages(items.length, pageSize);
  const clampedPage = clampPage(page, totalPages);
  const start = (clampedPage - 1) * pageSize;

  return items.slice(start, start + pageSize);
}

export function getVisibleRange(
  itemCount: number,
  page: number,
  pageSize: number,
): { start: number; end: number } {
  if (itemCount <= 0) {
    return { start: 0, end: 0 };
  }

  const totalPages = getTotalPages(itemCount, pageSize);
  const clampedPage = clampPage(page, totalPages);
  const start = (clampedPage - 1) * pageSize + 1;
  const end = Math.min(clampedPage * pageSize, itemCount);

  return { start, end };
}
```
