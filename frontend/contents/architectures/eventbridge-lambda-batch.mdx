# EventBridge + Lambda バッチ処理構成

## 概要

EventBridgeで決まった時刻にイベントを発生させ、Lambdaを実行するサーバーレスなバッチ処理構成です。

毎日1問配信、定期レポート作成、古いデータの整理、集計処理などに使えます。

本プロジェクトでは、将来的な「毎日1問配信」や「学習リマインド」に応用できます。
