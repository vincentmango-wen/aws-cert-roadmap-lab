# 差し替え用WBS：Phase 5 グローバルSEO・ローカライゼーション

## 情報源確認結果

* 確認できた情報：

  * 現行の Phase 5 は「学習アプリ化」で、ログイン・学習履歴・復習機能が対象。
  * MVPでは、ログイン、Cognito、有料会員機能、AI自動解説などは作らない方針。
  * 用語・比較・問題・構成図・ブログは、Markdown / MDX / JSON を中心に管理する方針。
  * SEO記事、用語集、比較記事、模擬問題、構成図解説を収益化導線にする構想がある。
* 不足している情報：

  * 既存設計書には多言語URL、hreflang、多言語sitemap、多言語コンテンツ管理の設計がまだない。
* 今回の前提：

  * 日本語URLは既存のまま維持。
  * 英語は `/en`。
  * 中国語は `/zh`。繁体字寄りで開始し、将来 `/zh-cn` を追加可能にする。
  * Phase 5を「学習アプリ化」から「グローバルSEO・ローカライゼーション」に差し替える。
  * 学習アプリ化・有料化は Phase 6 に後ろ倒しする。
* 実装への影響：

  * Cognito、DynamoDB追加、決済機能は今回不要。
  * S3 + CloudFront の静的配信構成を維持。
  * Next.js の静的export対象ページが増える。
  * sitemap、metadata、canonical、hreflang の実装が必要。

現行WBSではPhase 4が収益化準備、Phase 5が学習アプリ化になっているため、今回の差し替え対象はPhase 5です。
また、現行設計ではMVPのコンテンツ管理はMarkdown / MDX / JSON中心で、問い合わせ以外のDynamoDB利用は最小化する方針です。

# 2. Phase 5 の目的

Phase 5 の目的は、単なる翻訳ではありません。

**目的は、英語圏・中国語圏からの検索流入を検証し、AWS資格学習サイトとしてグローバルSEOの土台を作ることです。**

競合分析を踏まえると、英語圏で「AWS Cloud Practitioner practice exam」のようなビッグキーワードを狙うのは厳しいです。
狙うべきは、以下です。

```text
AWS資格対策
× 初学者向け
× 用語集
× サービス比較
× 構成図
× 日本語・英語・繁体字中国語
× 実装ポートフォリオ
```

# 4. Phase 5 でやらないこと

| やらないこと            | 理由                                    |
| ----------------- | ------------------------------------- |
| Cognitoログイン       | ローカライゼーション検証には不要                      |
| 学習履歴保存            | ユーザー登録が必要になり、スコープが重くなる                |
| Stripe決済          | 流入検証前に有料化しても転換率を判断できない                |
| 有料会員機能            | コンテンツ価値と海外流入を先に検証する                   |
| 翻訳API本番連携         | API費用と品質管理コストが増える                     |
| IPベース自動リダイレクト     | Googlebot、AdSense審査、ユーザー確認で挙動が読みにくくなる |
| DynamoDBへのコンテンツ移行 | 静的JSON / MDXの方がSEO、速度、コストで有利          |
| WAF導入             | 現段階では固定費・運用負荷が増える                     |
