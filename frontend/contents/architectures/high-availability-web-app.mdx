# ALB + Auto Scaling + RDS Multi-AZ 高可用性構成

## 概要

複数AZにEC2を配置し、ALBでリクエストを分散し、Auto Scalingで台数を調整し、RDS Multi-AZでDB障害に備える構成です。

本格的なWebアプリケーションの基本形であり、SAAで頻出する構成です。

本プロジェクトのMVPでは低コストを優先するため採用しませんが、面接でAWS設計力を説明するときに重要な構成です。
