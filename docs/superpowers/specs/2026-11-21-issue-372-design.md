# Issue #372: readable question stems

The detail page currently renders the question as a 24px/30px heading but the answers as 14px/16px body text. Long prompts are difficult to scan. This change preserves the rank-one heading and makes the stem and answer text use the same responsive font size and line-height; font weight still distinguishes the heading. The stem keeps natural wrapping, including an overflow-wrap fallback for unbroken text.

Use localized, editorially selected break starts for long prompts such as SAA-068 (scenario, organization/constraints, closing ask). A small presentation map can add further exceptions without modifying canonical question data or guessing sentence boundaries with a regular expression. Preserve one accessible heading by presenting its phrasing children as block spans, not nesting paragraphs in a heading or issuing a second/redundant screen-reader heading. Preserve exact canonical text across those spans, including the whitespace already present at each boundary. An undefined, missing, or out-of-order marker falls back to one contiguous stem, not partial or altered content.

Other stems continue as an undivided heading. This change does not affect URLs, exam data, SEO, links, interactions, explanations, or answer keys. It is separately scoped from announcement #370 and exam addition #369. Verify a long and short released example in all three languages, responsive typography and overflow using an actual renderer if feasible.

Editorial scope after auditing all 68 SAA and 52 CLF stems across all three locales: use the six longest prompts in the combined-length heuristic (sum of JA and ZH character count plus EN count divided by 2.5), and validate the resulting conceptual break positions manually. The heuristic is for editorial discovery only, never runtime layout. The chosen IDs are SAA-053, SAA-057, SAA-059, SAA-062, SAA-067 and SAA-068. These include policy evaluation, concurrency constraints, cost evidence, DNS reachability, access pattern and write distribution, and query scope. CLF prompts top out at 117 JA, 238 EN, and 76 ZH characters and remain short enough to present as a single group. To extend coverage, review translated meaning and add a unique start marker for each constraint and ask paragraph in every locale; add or extend a parity case without changing the source question.
