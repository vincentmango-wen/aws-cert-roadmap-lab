# API Gateway + Lambda + DynamoDB サーバーレスAPI構成

## 概要

API GatewayをAPIの入口にし、Lambdaで処理を実行し、DynamoDBにデータを保存する構成です。

本プロジェクトでは、問い合わせフォームの送信内容を保存するAPIとして利用します。

常時起動サーバーを持たないため、小規模なWebアプリや個人開発のMVPと相性が良い構成です。
