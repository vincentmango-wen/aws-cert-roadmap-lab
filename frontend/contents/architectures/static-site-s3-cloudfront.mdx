# S3 + CloudFront 静的Webサイト構成

## 概要

S3に保存したHTML、CSS、JavaScript、画像ファイルを、CloudFront経由でユーザーに配信する構成です。

この構成は、ブログ、学習サイト、ポートフォリオサイト、ドキュメントサイトなど、サーバー側で毎回処理を行わない静的コンテンツに向いています。

本プロジェクトでは、AWS資格学習サイトのMVP公開構成として使います。

## 構成図

```mermaid
flowchart TD
    User[ユーザー]
    R53[Route 53 任意]
    ACM[ACM 証明書 任意]
    CF[CloudFront]
    OAC[Origin Access Control]
    S3[(S3 静的ファイル)]
    IAM[IAM]
    Budget[AWS Budgets]

    User -->|HTTPSアクセス| CF
    R53 -.独自ドメイン利用時.-> CF
    ACM -.TLS証明書.-> CF
    CF -->|OAC経由で取得| S3
    OAC -.S3直接公開防止.-> S3
    IAM -.最小権限.-> S3
    Budget -.課金監視.-> CF
    Budget -.課金監視.-> S3
