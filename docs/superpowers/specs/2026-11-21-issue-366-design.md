# #366 comparison article editorial design

The reader should be able to answer two questions quickly: which service fits, and which AWS documentation substantiates the distinction. At the examined baseline there are 15 published comparison articles and 45 body files, with no missing translated body. The audit in the accompanying #366 report lists every locale and original section sequence and source classification. Two editorial samples are published: ALB/NLB/CloudFront and API Gateway/ALB/CloudFront. The fragment `api-gateway-vs-cloudfront` may refer to the latter subject, but its exact intended source is unconfirmed. It remains absent and no route will be added.

## Shared outline

| Role | Traditional Chinese | Japanese | English | Rule |
|---|---|---|---|---|
| Opening answer | 選擇重點 | 選択のポイント | Selection at a glance | Required; give a short rule for what to choose |
| Comparison | 比較表 | 比較表 | Comparison table | Required; preserve dimensions and qualifications |
| Context | 入門說明 | 初学者向け説明 | Beginner context | Optional when the first two sections suffice |
| Exam | 考綱與判斷重點 | 試験ガイドと判断のポイント | Exam guide and decision cues | Optional if article has no exam-oriented material; use official scope, not guessed frequency |
| Practice | 實務選型 | 実務での使い分け | How to choose in practice | Required; existing scenarios can retain subheadings |
| Misconceptions | 常見誤解 | よくある誤解 | Common misconceptions | Required; distinguish qualifications and false shortcuts |
| Summary | 總結 | まとめ | Summary | Required |
| References | AWS 官方參考 | AWS公式リファレンス | Official AWS references | Required; group descriptive source links by topic or service |
| Related | 相關用語／相關題目 | 関連用語／関連問題 | Related terms / questions | Optional, after references |
| Corrections | 更正說明 | 訂正内容 | Corrections | Existing only, last, preserve raw recorded history |

Use the same hierarchy and source destinations across locales; retain contextual inline citations and existing correction citations. Prefer AWS developer/user guides specific to the claim; use official exam content outlines for scope and pricing pages only where needed. Never add inferred exam frequency or a fake technical correction. Preserve slugs, registries, frontmatter, metadata, redirects and component behavior. The latest owner approval waives intermediate confirmation only for this overnight task; it does not grant publication.
